# My Akiba 📚✨🎥

Welcome to **My Akiba**, a Large Scale and Multi-Structured Database project. My Akiba represents your go-to platform for tracking and discovering anime and manga! This application connects fans with shared tastes, providing recommendations, analytics, and social features in a sleek, user-friendly environment.

## 🚀 Features

- **Manga & Anime Tracking**: Keep track of your progress with personalized lists.
- **Social Interactions**: Follow users, explore their lists, and connect with fans.
- **Smart Recommendations**: Get suggestions based on your taste and trends.
- **Admin Tools**: Manage the catalog, moderate reviews, and analyze user activity.
- **Scalable Performance**: High availability and fast responses for large-scale data.

## 🛠️ Tech Stack

- **Backend**: Spring Framework, RESTful APIs
- **Databases**: MongoDB (Document Store), Neo4j (Graph DB)
- **Security**: JWT for authentication, encrypted passwords
- **Dataset**: Curated from MyAnimeList API

## 📂 Repository Structure

- `/src`: Core application code
- `/models`: Data models for MongoDB and Neo4j
- `/controllers`: API endpoints for users, media, and admin features
- `/services`: Business logic and analytics

## 🌐 API Highlights

- **Authentication**: `POST /api/auth/register`, `POST /api/auth/login`
- **User Operations**: Manage profiles, lists, and followers.
- **Media Management**: Browse, review, and track anime/manga.
- **Admin Analytics**: Gain insights into trends, user activity, and media performance.
- **Recommendations**: Discover content and users with shared interests.
